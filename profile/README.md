## Who We Are

Robot Friends is a community of builders, tinkerers, and AI enthusiasts who believe the best way to learn is by doing — and doing it together.

We're developers, domain experts, entrepreneurs, and curious people who got excited about what AI tools like Claude Code can actually do in the hands of someone who cares. We build things, share what we learn, help each other get unstuck, and have a good time doing it.

The Discord is home base. This GitHub org is where we put the work.

---

## What You'll Find Here

Community-built tools for developers using AI coding agents. Practical, opinionated, built for real daily use. Everything is MIT licensed — take it, fork it, make it yours.

| Repo | What It Does |
|------|-------------|
| [no-look-pass](https://github.com/Robot-Friends-Community/no-look-pass) | Context handoff for Claude Code — never lose your work mid-session. Includes Instant Replay game film logging. |
| [hail](https://github.com/Robot-Friends-Community/hail) | Voice notifications for Claude Code agents — 14 voice packs so you can stop staring at the terminal. |

More coming. The community is just getting started.
