**Robot Friends builds AI tools with good vibes — small, friendly, open-source tools that give you your best hours back.**

We're a community of builders and AI enthusiasts who think powerful software should also be approachable, fun, and real. We build tools, share what we learn, help each other get unstuck, and have a good time doing it. Discord is home base — this is where we put the work. Poke around, use what helps, and if you want to build something with us, pull up a bench. `:)`

### 🧰 The Toolbox

<!-- BEGIN:ORG-INVENTORY (edit by hand; keep one row per public repo) -->
Our developer tools are institutions with a mandate — each one runs a piece of the plumbing so you don't have to remember it.

| Tool | The institution | What it does |
|---|---|---|
| **[Airport Authority](https://github.com/Robot-Friends-Community/airport-authority)** | the tower | Session continuity & project-lifecycle control for Claude Code — trust the tower, never lose a session. |
| **[Customs Authority](https://github.com/Robot-Friends-Community/customs-authority)** | the border | The decision-layer toolkit for Claude Code — every small judgment in your app inspected in 100 ms, stamped with a confidence, escalated when unsure. Built on TypeSafe's Jev. |
| **[DoPA](https://github.com/Robot-Friends-Community/dopa)** | the port | Department of Port Authorities — local-dev port registry, inspector, and do-not-kill guard. Stop killing each other's dev servers. |
| **[Hail](https://github.com/Robot-Friends-Community/hail)** | the signal station | Voice notifications for Claude Code — audio alerts so you can stop staring at the terminal. |
| **[no-look-pass](https://github.com/Robot-Friends-Community/no-look-pass)** | the one-skill handoff | Context handoff for Claude Code, the lightweight edition — save your state, clear, pick it back up. |
| **[toolbox](https://github.com/Robot-Friends-Community/toolbox)** | the directory | Every RF tool, web and developer — and what's coming next. |
<!-- END:ORG-INVENTORY -->
